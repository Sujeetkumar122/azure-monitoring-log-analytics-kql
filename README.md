# 📊 Azure Monitoring & Log Analytics (KQL Queries)

A collection of practical **Kusto Query Language (KQL)** queries for monitoring Azure Virtual Machines, Storage, and Infrastructure in **Azure Log Analytics Workspaces**.

## 📁 Queries Included
- CPU utilization tracking & spike detection
- Disk space alerting (< 15% free space)
- Failed operations audit from Azure Activity Logs
